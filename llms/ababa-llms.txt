# ABABA (株式会社ABABA)

> Japanese new-graduate direct-recruiting platform. Only students who have reached the
> FINAL interview stage at another company may register, submitting evidence of that
> selection history, so every candidate is pre-qualified by another employer's hiring bar.
> Employers scout those near-miss finalists into abbreviated selection flows. A second
> product, REALME, runs AI mock interviews and matching. ABABA ships as an end-user web
> application and publishes no public API.

## Status for agents

- **No public API.** ABABA publishes no developer portal, API reference, OpenAPI/AsyncAPI/
  GraphQL specification, SDK, CLI, webhook catalog, MCP server, or A2A agent card.
- **No /.well-known/ surface.** Probed 2026-09-05 across ababa.co.jp, hr.ababa.co.jp and
  api.ababa.co.jp: zero documents served.
- **No llms.txt of the provider's own.** This file is generated by API Evangelist from the
  public record; it is not published by ABABA.
- `hr.ababa.co.jp` answers HTTP 200 with a marketing shell for every unknown path — treat
  its 200s as soft-404s and read the sitemap, not guessed routes.
- `ababa.co.jp` (the application host) serves `robots.txt` with `Disallow: /` for all user
  agents. Do not crawl it.
